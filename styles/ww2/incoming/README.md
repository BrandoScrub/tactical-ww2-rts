# Incoming textures (raw, from ChatGPT, 2026-11-20)

Unprocessed originals, 1254 px (JPEG q93). Not loaded by the game. `python3 tools/prepare_tiles.py` turns them into
the finished tiles in `styles/ww2/tiles/` (and `art/ground/` for ground tiles): seam fixes, whole rows, colour
matching. Each texture's steps are listed in that script. To redo a texture, replace its file here and rerun.
